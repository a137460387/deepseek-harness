# Agent Note: Reasoning-effort editing on the Models page model list

Status: implemented

English | [中文](2026-09-18-model-list-reasoning-efforts.md)

## 问题

pi-ai 按模型的 `reasoningEfforts` 字段——可选的思考等级及各等级派发时使用的线上值——此前只能手改 `settings.yaml`。Models 页的模型编辑器只覆盖 id、显示名称和两个 token 容量，而提供方卡片刻意不设提供方级的推理控件，因为该能力按模型持有、同一提供方下的各模型并不一致。模型不在已安装目录中的提供方（一个服务多家厂商的中转网关）因此在任何地方都没有可选的推理等级：对未声明的模型，适配器不报告该能力，而 composer 的模型选择器读取的正是这份元数据，其推理等级面板因此为空。

## 决策

Models 页的每个 pi-ai 模型行在自己的展开区编辑自己的 `reasoningEfforts`，共三种模式：跟随已安装目录（字段缺席）、声明该模型不推理（`false`）、或把所提供的等级声明为以等级为键、线上值为值的字典。

- **等级词汇表来自 schema 读取，不是客户端副本**：`reasoningLevels` 在所属 namespace 的 `Config` schema 中走到 `reasoningEfforts` union 的 dict 成员并读取其键 union——与适配器校验所用的是同一来源，和 `protocolChoices` 读取线上协议是同一模式。`nodeAtPath` 每层容器消耗一个路径段，因此路径在 `models` 之后先命名一个（被忽略的）元素位置、再命名字段键。schema 缺少该字段或形状不可读时返回空列表，控件不渲染，而不是渲染一个写入会被拒绝的控件。
- **自定义模式每次编辑都从词汇表重建字典**，而不是在存储值上展开：`off` 保持声明（留空存为 null，解析器读作「支持，发送时不带字段」；已存的拼写会保留），词汇表之外的键与留空的非 off 等级则被剔除——经过本编辑器的一次编辑就是修复手写漂移的时机（即 llm-pi-ai 注册测试钉住的 YAML-1.1 `off:` → `false:` 键改写），这类漂移会被 section schema 整体拒绝。
- **构建期不变式在客户端镜像**：`validateDeepSeekModels` 拒绝未提供任何 `off` 以外等级的声明、非 off 等级的 null 线上值、非字符串或空字符串线上值、以及既非字典也非 `false` 的字段，使拒绝在写入前指名模型行，而不是在 section 层以 schema 报文出现。
- **存储形状如实渲染**：`false` 选中关闭，字典选中自定义并把拼摆放进字段（null 渲染为空），无值的存储声明读作自定义并在保存时被拒绝，把修复引向同一个控件。
- deepseek 家族的目录行不渲染该控件：其 schema 没有该字段，编辑器也不会收到词汇表。

composer 的选择器继续从目录元数据读取等级；该路径没有任何变化。

## 已考虑的替代方案

**卡片上的提供方级推理控件。** 既有理由仍然成立：路由级的单一取值对每个不一致的模型都是错的，composer 选择器会提供适配器按模型拒绝的等级。在卡片上落败；按模型行才是与字段自身形状匹配的家。

**客户端硬编码等级列表。** 它会恰恰在协议列表已经需要从 schema 读取的地方漂移出适配器接受的集合。落败：保持单一事实来源，内省失败时退化为「无控件」而不是「会写入被拒绝值的控件」。

**只修复受影响部署的 `settings.yaml`。** 修复一个提供方，留下编辑能力缺口；线上拼写是部署侧知识，编辑器应当收集它，而不是由本仓库发明默认值。

## 后果

运维者无需手改 YAML 即可为自定义中转启用推理等级，composer 选择器经由既有元数据路径提供这些等级。通过编辑器编辑某一行会规范化手写字典——词汇表外的键被剔除、`off` 被物化——因此想要「其他等级可用但 off 不可用」的部署仍留在 YAML 一侧。词汇表读取是每次编辑器挂载一次的 schema 内省；字段缺失时隐藏控件而不影响卡片。

## 测试

`provider-form.client.spec.tsx` 钉住词汇表内省（夹具 schema、undefined namespace、无该字段的 schema）、自定义模式流程（仅 off 的拒绝，随后是存储字典 `{ off: null, high: 'high' }`）、编辑已存声明（拼摆放进字段、失焦收敛、被清空的等级离开字典、off 拼写在无关编辑后保留）、关闭写入 `false`、继承移除字段、无值存储声明读作自定义并被拒绝、以及镜像解析器的校验形状矩阵。`components.client.spec.tsx` 钉住 deepseek 目录行不渲染控件。
