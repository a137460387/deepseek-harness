# @deepseek-ai/dsh-client-usage-stats

[English](README.md) | 中文

## 概述

Web UI 的使用统计，以设置弹窗中的一个标签页呈现：按提供方与模型拆分的 token 总量，按天与按月聚合，配有顶部统计卡片（累计、单日峰值、当前与最长连续天数）、GitHub 风格的活动日历、按时间范围的趋势折线图、各路由占比的环形图、月度明细列表，以及当前范围日数据的 CSV 导出。只统计 token 数量——永远不做价格换算（各家代理商计费不同，本界面从不把 token 折算成钱）。

## 数据流

本包是同一投影键上的双面插件：

- **Node 半边**（`exports["."]`）注册 `usageStats` 会话投影单元，以与 `tokenUsage` 相同的口径折叠持久日志——带 `(turn, step)` 替换语义的分片样本，加上压缩摘要调用的用量——但按 UTC 刻钟与提供方路由（`request/header` 归属；`compaction/summary` 自带路由）分桶。
- 递送走标准投影机制：`session/projection` 实时推送帧、持久化投影缓存、会话列表基线行——本包不拥有任何通道。
- **浏览器半边**（`exports["./client"]`）通过 `settings.section` 插槽挂载设置页（order 25，排在 Agent 预设之后）。控制器从列表基线读取每个会话的值，并对基线早于本单元的会话经 history 尾页补洞——该页的 `projections` 块会用全部已注册单元折叠整条日志。

## 聚合

刻钟桶（而非小时桶）保证任何 IANA 时区偏移——:00、:15、:30、:45——都落在桶边界上，客户端因此能把桶精确重组为本地日与月。全部日历换算都在客户端按浏览器时区进行；主机侧不感知任何时区。天/月/连续/峰值与范围窗口（近 7 日 / 近 30 日 / 本月 / 全部时间）都是同一批桶的纯重分组。

<a id="model-experience"></a>
## 模型体验

无。该插件只计算已记录用量的读模型，不注册任何模型可见内容：无提示词、消息、schema、工具或模型调用。

#### KV Cache 影响

无；本包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

<a id="known-limitations-and-deferred-work"></a>

- **标签页内不实时流式更新**——控制器在页面打开与点击刷新时收集数据；页面停留期间新增的用量要刷新后才出现。主要内容是历史总量，滞后只影响观感。
- **口径继承 `tokenUsage`**——主循环请求与压缩摘要调用；辅助标题生成（`session-title-llm`）不记录用量，不计入（见 token-meter README 的限制条目）。
- **环形图是全历史口径**——范围选择器只作用于趋势图；占比视图回答的是"哪条路由总体占主导"。
- **CSV 导出仅覆盖范围内的日总量**——下载内容是每个可见日一行 `day,total`；路由拆分留在标签页内。
- **活动日历最多 53 周**——一年以前的用量仍计入所有顶部数字，只是不再出现在日历网格里。
- **补洞限并发且缓存**——基线早于本单元的会话经 history 尾页重折叠，最多 8 路并发；完成的补洞在基线仍缺键的后续刷新中复用（失败的补洞会重试），因此只有首次打开承担折叠开销。
- **组合缺失提示只认确认缺失**——当每个观察到的会话的 history 尾页成功返回且都缺少该键时提示才出现，这恰好等价于"主机组合未注册本单元";补洞出错(调用被拒或传输抛错)的会话状态未知,不会喂给该提示。
- **图表色板只有五个色相**——第六个及以后的系列共用一个中性色；图例仍以名称区分。
